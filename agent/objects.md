# Objects & vehicles

Use the id in `[OBJECT: id x=… z=… scale=…]`. Sizes are in set units (a person is about 330 tall). z is depth: 0 is the actors' line, negative is in front of them, 60 is just behind, 300 far back. Vehicles can drive (drive beats in the studio).
